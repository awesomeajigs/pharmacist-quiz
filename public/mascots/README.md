# Mascot images

Drop your exported mascot PNGs from Figma here, named exactly:

- counselor.png
- detective.png
- sprinter.png
- mentor.png
- guardian.png

The app automatically uses these once present (falls back to a simple
colored SVG placeholder if a file is missing) — no code changes needed.

To export from Figma: select each mascot image layer -> right panel ->
Export -> PNG -> Export. Recommended size: at least 512x512px.
